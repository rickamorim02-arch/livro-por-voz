# Livro por Voz

Aplicativo mobile/PWA para construir um livro a partir de gravações de voz.

Fluxo: **áudio original → transcrição literal → texto trabalhado → capítulos → livro**.

A V1 preserva os dados localmente no navegador do aparelho e permite gravar/importar áudio, manter transcrição e versão trabalhada separadas, organizar capítulos e exportar backup em TXT.

> A transcrição automática por IA será a próxima integração; a V1 não finge transcrever áudio no navegador sem um serviço de reconhecimento configurado.
